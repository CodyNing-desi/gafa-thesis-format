# gafa-thesis-format

一个可移植的 Harness Skill，用于让 Agent 在收到“按广美毕设论文格式改”之类的指令后，自动加载广州美术学院本科毕业论文 / 创作（设计）报告书排版规范。

## 推荐调用语句

- 按广美毕设论文格式改这个 DOCX。
- 用 gafa-thesis-format 检查并修正全文格式，只改格式，不改内容。
- 按广美模板重排，并生成自动目录、处理图表题与页码。

## 文件

- `SKILL.md`：Agent 入口与执行流程
- `references/format-spec.md`：完整格式规范
- `references/qa-checklist.md`：最终检查清单
- `assets/广州美术学院本科毕业论文模板.docx`：原始权威参考模板
