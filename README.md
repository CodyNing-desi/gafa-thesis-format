# gafa-thesis-format

一个可移植的 Agent Skill，用于让 AI Agent 在收到“按广美毕设论文格式改”之类的指令后，自动按**广州美术学院本科毕业论文 / 创作（设计）报告书**官方模板完成排版与格式审查。

规范中的全部规则均已通过解包官方模板（附件6《广州美术学院毕业论文参考范文模板》）的 OOXML 逐段实测核实，而非仅凭范文中的文字标注；页码、分节、字号、行距、边距等均以模板 XML 实际取值为准。

## 触发方式

安装后，对 Agent 说：

- 按广美毕设论文格式改这个 DOCX
- 用 gafa-thesis-format 检查并修正全文格式，只改格式，不改内容
- 按广美模板重排，并生成自动目录、处理图表题与页码

## 安装

将本仓库克隆到 Agent 的 skills 目录（路径按所用 Harness 调整）：

```bash
git clone https://github.com/CodyNing-desi/gafa-thesis-format.git ~/.agents/skills/gafa-thesis-format
```

## 格式规范速览

| 项目 | 要求 |
|---|---|
| 页面 | A4，四边 25 mm（致谢 + 创作/设计说明所在末节左右约 31.7 mm，随模板） |
| 中文正文 | 小四宋体，1.5 倍行距，首行缩进 2 字符 |
| 英文 / 阿拉伯数字 | Times New Roman，字号与所在中文相同 |
| 一级标题 | 小二黑体加粗，居中，段前后各 1 行 |
| 二级标题 | 小三黑体加粗，左对齐，段前后各 0.5 行 |
| 三级标题 | 四号黑体加粗，左对齐，段前后各 0.5 行 |
| 图题 / 表题 | 图下表上，五号宋体居中，按章编号（图 1-1 / 表 2-1） |
| 目录 | `TOC \o "1-3" \h \u` 自动生成，含摘要/Abstract，不含声明/授权书/目录自身 |
| 引用 | 方括号编号上标（如 `……绿色建筑[1]。`） |
| 参考文献 | `[1]` 编号，小四宋体；[M] [J] [N] [C] [P] [S] [R] [EB/OL] [D] |
| 摘要 | 中文 300–600 字；关键词 3–7 个，全角分号分隔，末尾无标点 |

### 页码与分节（XML 实测核实）

| 部分 | 页码 |
|---|---|
| 封面 / 学术诚信声明 / 授权书 / 目录 | 无页码 |
| 中文摘要 / Abstract | 大写罗马数字 I、II（从摘要重新起算） |
| 第一章 起 | 阿拉伯数字从 1 开始，此后连续编号到文末 |

完整的 12 节分节结构与重建要点见 [`references/format-spec.md`](references/format-spec.md) §15；常见实现陷阱（模板 Normal 样式为仿宋、标题加粗在样式层、封面残留页眉页脚等）见 §17。

## 文件结构

- `SKILL.md`：Agent 入口与执行流程
- `references/format-spec.md`：完整格式规范（含分节、页码、实现陷阱）
- `references/qa-checklist.md`：交付前逐项检查清单
- `assets/广州美术学院本科毕业论文模板.docx`：官方参考模板（附件6 范文）

## 说明与版权

- 排版规则提炼自仓库内随附的官方范文模板；若学院另行发布新版要求，以新版为准。
- `assets/` 中的模板 docx 版权归广州美术学院所有，此处仅作格式参考分发。
- Skill 只处理排版格式，不改写论文内容。
