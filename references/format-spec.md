# GAFA 本科毕业论文 / 创作（设计）报告书格式规范

> 来源：用户提供的广州美术学院标准模板。该文件用于 Harness 执行排版时的操作性规范。

## 1. 页面与正文通用设置

| 项目 | 要求 |
|---|---|
| 纸张 | A4 |
| 页边距 | 上、下、左、右均 25 mm |
| 中文正文 | 小四号宋体 |
| 英文字母 / 阿拉伯数字 | Times New Roman，字号与所在中文相同 |
| 正文行距 | 1.5 倍行距 |
| 正文首行 | 缩进 2 个汉字宽度 |
| 正文对齐 | 两端对齐（模板示例） |

## 2. 论文结构顺序

建议按模板顺序组织：

1. 封面
2. 学术诚信声明
3. 学位论文版权使用授权书
4. 目录
5. 中文摘要
6. 英文 Abstract
7. 正文各章
8. 结论
9. 参考文献
10. 致谢
11. 毕业创作（设计）说明（如适用）

页码与分节的精确方案见 §15（已按模板 XML 实测核实）；目录条目范围见 §4。

## 3. 封面

### 报告书类型标题

“本科毕业论文/创作（设计）报告书”按实际类型选择：

- 本科毕业论文
- 本科毕业创作报告书
- 本科毕业设计报告书

格式：**小初号黑体加粗**。

### 论文题目

- 二号黑体加粗
- 下划线
- 居中
- 1.5 倍行距

### 学生信息区

包括：

- 学生姓名
- 学号
- 所在学院
- 专业·方向
- 指导教师
- 提交日期

模板示例采用规整对齐布局；编辑时尽量保留模板布局，不自行设计新的封面体系。

## 4. 目录

### “目 录”标题

- 小二号黑体加粗
- 居中
- 1.5 倍行距
- 两字之间空 2 个字符
- 段前 1 行
- 段后 1 行

### 目录内容

- **必须由电脑自动生成**
- 各章标题、结论、参考文献、附录（可选）、致谢：四号黑体，左对齐，1.5 倍行距
- 次级标题及题序：小四号宋体，1.5 倍行距
- 模板使用真实自动目录域 `TOC \o "1-3" \h \u`（1–3 级大纲级别、带超链接），外层套 Word 内容控件（SDT）；重建时保留该域结构，不要手敲点线和页码
- 目录条目含“摘 要 / Abstract”（其页码为罗马数字）；不含封面、学术诚信声明、授权书、目录自身

## 5. 中文摘要

### 标题“摘 要”

- 小二号黑体加粗
- 居中
- 1.5 倍行距
- 两字之间空 2 个字符
- 段前、段后各 1 行

### 摘要正文

- 300–600 字
- 小四号宋体
- 1.5 倍行距
- 首行缩进 2 个汉字
- 字母与阿拉伯数字用 Times New Roman

### 关键词

摘要正文结束后空 1 行。

- “关键词：” 小四号黑体加粗，左对齐，1.5 倍行距
- 关键词正文：小四号宋体
- 3–7 个关键词
- 关键词之间用中文分号 `；` 分隔
- 最后一个关键词不加标点

## 6. 英文摘要

英文摘要和关键词应为中文摘要、关键词的翻译。

### `Abstract`

- 小二号 Times New Roman 加粗
- 居中
- 1.5 倍行距
- 段前、段后各 1 行

### 英文摘要正文

- 小四号 Times New Roman
- 1.5 倍行距
- 两端对齐
- 段首缩进两个汉字宽度

### `Key Words` / `Keywords`

模板正文示例使用 `Key Words:`，说明文字使用 `Keywords`。排版时优先保持用户文档或模板既有写法一致，不自行制造两套风格。

- 标签：小四号 Times New Roman 加粗，左对齐，1.5 倍行距
- 关键词：小四号 Times New Roman
- 3–7 个
- 用全角分号 `；` 分隔（模板英文样例亦使用全角分号）
- 最后一个不加标点

## 7. 正文标题层级

| 层级 | 示例 | 格式 |
|---|---|---|
| 一级标题 | 第一章 绪论 | 小二号黑体加粗，居中，1.5 倍行距，段前/段后各 1 行 |
| 二级标题 | 1.1 研究背景与意义 | 小三号黑体加粗，左对齐，1.5 倍行距，段前/段后各 0.5 行 |
| 三级标题 | 1.1.1 研究背景 | 四号黑体加粗，左对齐，1.5 倍行距，段前/段后各 0.5 行 |
| 正文 | — | 小四号宋体，1.5 倍行距，首行缩进 2 个汉字 |

一级标题中的章节序号与标题之间空 1 个字符，例如：

`第一章 绪论`

实现备注（XML 实测）：一至三级标题分别套用内置 heading 1/2/3 样式（大纲级别 0/1/2），加粗定义在样式层（正文样例的 run 层并无加粗标记），字体与字号在段落/run 层覆盖。三级标题段落自带 `left=720 hanging=720` 缩进，首行仍从页边距起，仅影响折行。重排时务必保留样式层加粗，只覆盖字号字体。

## 8. 正文文献引用

模板采用数字顺序编码。

### 一般引用

文中引用序号：

- 小四号 Times New Roman
- 方括号
- 上角标形式

示意：`……绿色建筑[1]。`

### 正文直接点名文献

如果引用编号是句子语法的一部分，则与正文基线对齐，例如：

`由文献[4-7]可知……`

连续多篇文献按模板示例处理。

## 9. 图片

- 图题位于图片**下方**
- 图题五号宋体
- 居中
- 1.5 倍行距
- 图序按章编号，例如：`图 1-1`
- 图号与图名之间空 1 格
- 子图编号使用 `a)`、`b)` 等，置于分图下方

示意：

`图 1-1 我国绿色建筑实践`

## 10. 表格

- 表题位于表格**上方**
- 一般五号宋体
- 居中
- 1.5 倍行距
- 表序按章编号，例如：`表 2-1`
- 表号与表名之间空 1 格
- 跨页续表：编号、标题后加 `（续）`
- 跨页时重复表头
- 表格不加左、右列线
- 空缺数字单元格用 `—`
- 表中文字五号宋体

## 11. 结论

### “结 论”标题

- 小二号黑体加粗
- 居中
- 1.5 倍行距
- 中间空 2 个字符
- 段前、段后各 1 行

### 正文

- 小四号宋体
- 1.5 倍行距
- 首行缩进 2 个汉字
- 字母与阿拉伯数字使用 Times New Roman

## 12. 参考文献

### 标题

- 小二号黑体加粗
- 居中
- 1.5 倍行距
- 段前、段后各 1 行

### 文献正文

- 小四号宋体
- 1.5 倍行距
- 字母和阿拉伯数字 Times New Roman
- 编号形式 `[1]`、`[2]`……

模板给出的文献类型包括：

- `[M]` 学术著作
- `[J]` 期刊论文
- `[N]` 报纸文章
- `[C]` 论文集 / 会议录
- `[P]` 专利
- `[S]` 技术标准
- `[R]` 报告
- `[EB/OL]` 电子文献
- `[D]` 学位论文

不要未经用户要求将整套参考文献改成 APA、Chicago、IEEE 等其他体系。

## 13. 致谢

### “致 谢”标题

- 小二号黑体加粗
- 居中
- 1.5 倍行距
- 两字之间空 2 个字符
- 段前、段后各 1 行

### 正文

- 小四号宋体
- 1.5 倍行距
- 首行缩进 2 个汉字
- 字母与阿拉伯数字 Times New Roman

## 14. 毕业创作（设计）说明

如论文属于创作 / 设计类：

- 展示毕业创作（设计）彩图
- 系列作品最多 5 页
- 可用 A3 打印，但须折叠成 A4 规格
- 作品说明 300 字以内
- 作品说明正文：小四号宋体，1.5 倍行距，首行缩进 2 个汉字
- 该部分与致谢同处文档最后一节，此节页边距与正文不同：左右 1800 缇（约 31.7 mm）、上下 1440 缇（约 25.4 mm）；照模板处理时不要擅自统一为 25 mm

## 15. 页码与分节（已按模板 XML 实测核实）

模板全文共 12 个节，均为“下一页”分节符，除最后一节外全部开启“首页不同”（titlePg）。页码显示方案：

| 部分 | 页码显示 |
|---|---|
| 封面 | 无页码 |
| 学术诚信声明 | 无页码（页脚为空） |
| 目录 | 无页码（页脚为空，且不列入目录条目） |
| 中文摘要 / 英文 Abstract | 大写罗马数字 I、II，从中文摘要重新起算 |
| 第一章 起 | 阿拉伯数字，从 1 重新起算 |
| 第二章至结论、参考文献、致谢、创作说明 | 阿拉伯数字连续编号，各节不重设起始值 |

目录域的缓存条目可佐证：`摘 要 I`、`Abstract II`、`第一章 绪论 1`、`结 论 10`、`参考文献 11`、`致 谢 13`。

重建分节时的操作要点：

1. 封面、学术诚信声明、目录三节的页脚留空（不要放 PAGE 域）；
2. 摘要节设置 `pgNumType fmt="upperRoman" start="1"`；正文首个节（第一章）设置 `pgNumType start="1"`（阿拉伯），其后各节不设 `pgNumType`，自然续接；
3. “无页码”靠“首页不同 + 首页页脚空”实现，不要靠删域或手打；
4. 模板摘要首页的“I”是手打字符而非域；重排时建议统一改用 PAGE 域，避免摘要超过一页后页码错位；
5. 学位论文版权使用授权书同样无页码、不入目录；
6. 不要把阿拉伯数字页码提前到摘要——模板中摘要是罗马数字、正文才是阿拉伯数字。

## 16. Word 中文字号换算

当编辑器只接受 point size 时，可按常用 Word 中文字号换算：

| 中文字号 | pt |
|---|---:|
| 小初 | 36 |
| 二号 | 22 |
| 小二 | 18 |
| 小三 | 15 |
| 四号 | 14 |
| 小四 | 12 |
| 五号 | 10.5 |

## 17. 模板内部实现备注与陷阱（XML 实测）

- **Normal 基础样式是仿宋_GB2312 16 pt**，模板所有实际格式靠段落直接格式覆盖为宋体小四。重排时必须逐段显式设置字体、字号、行距、缩进，不要依赖样式继承。
- 全部 12 节均为“下一页”分节符；除最后一节（致谢 + 毕业创作（设计）说明）外，其余各节均开启“首页不同”。
- 段前/段后“1 行 / 0.5 行”以 `beforeLines/afterLines`（行单位）实现，并配合文档网格 `linePitch=333` 兜底；不要改成随意磅值。
- 封面节的偶数页页眉残留另一篇范文的文字（“……员工流失问题研究”），因未开启奇偶页不同而不显示；封面页脚另有静态文本“1”（同为残留）。编辑真实文档时顺手清除这两处。
- 第一章被一个多余的分节符拆成两节（断在 1.1.2 之前），属模板制作粗糙；重排时不必效仿，正文每章一节即可。
- 标题加粗来自内置 heading 样式而非 run 层加粗（见 §7 实现备注）；重建样式时不要只复制 run 属性。

## 18. 优先级与不确定性原则

- 该规范只总结源模板明确支持的规则。
- 不补写源模板没有规定的学校政策。
- 若老师 / 学院另发最新版要求，与本 skill 冲突时，应以**最新版院系正式要求**为准，并更新该 skill。
- 如果用户要求“完全照模板”，可以直接复制 retained template 的样式、section、页眉页脚与自动编号结构，而不是仅凭文字重新搭建。
