# GAFA 毕设论文格式 QA Checklist

用于修改完成后的最终核验。

## 页面
- [ ] A4
- [ ] 四边 25 mm（致谢 + 创作/设计说明所在末节按模板放宽：左右约 31.7 mm、上下约 25.4 mm）
- [ ] section breaks 正常
- [ ] 封面、学术诚信声明、目录页无页码
- [ ] 中文摘要 / Abstract 为大写罗马数字 I、II（从摘要重新起算）
- [ ] 第一章起阿拉伯数字从 1 开始，此后连续编号到致谢/创作说明

## 封面
- [ ] 报告书类型正确
- [ ] 主标题小初黑体加粗
- [ ] 论文题目二号黑体加粗、下划线、居中、1.5 倍行距
- [ ] 姓名、学号、学院、专业、导师、日期完整

## 目录
- [ ] 自动生成，不是手敲页码
- [ ] 目录标题小二黑体加粗、居中
- [ ] 一级目录项四号黑体
- [ ] 次级目录项小四宋体
- [ ] 页码与正文一致
- [ ] 目录不含封面/声明/授权书/目录自身条目；摘要与 Abstract 条目页码为罗马数字

## 摘要
- [ ] 中文摘要 300–600 字
- [ ] 中文摘要标题格式正确
- [ ] 中文正文小四宋体、1.5 倍行距、首行 2 字
- [ ] 关键词 3–7 个，分号分隔，末尾无标点
- [ ] Abstract 与中文摘要内容对应
- [ ] 英文为 Times New Roman

## 正文
- [ ] 一级标题：小二黑体加粗居中
- [ ] 二级标题：小三黑体加粗左对齐
- [ ] 三级标题：四号黑体加粗左对齐
- [ ] 正文：小四宋体，1.5 倍行距，首行 2 字
- [ ] 英文和阿拉伯数字：Times New Roman
- [ ] 无孤立标题、异常分页或大块空白

## 图表
- [ ] 图题在下，表题在上
- [ ] 图题/表题五号宋体、居中
- [ ] 图表按章编号
- [ ] 子图编号规范
- [ ] 续表有“（续）”并重复表头
- [ ] 表格无左右列线
- [ ] 表内文字五号宋体

## 引用与参考文献
- [ ] 普通引用方括号编号、上标
- [ ] 句内直接点名文献编号与正文基线对齐
- [ ] 参考文献标题格式正确
- [ ] 参考文献正文小四宋体 + 英数 TNR
- [ ] 未擅自转换为 APA/IEEE 等其他格式

## 结论 / 致谢
- [ ] 标题小二黑体加粗、居中、段前后 1 行
- [ ] 正文小四宋体、1.5 倍行距、首行 2 字

## 最终渲染检查
- [ ] 每页均已渲染查看
- [ ] 无文字裁切
- [ ] 无图片遮挡/漂移
- [ ] 无表格溢出
- [ ] 无页码错位
- [ ] TOC 页码正确
- [ ] 中文字体与英文字体无异常替换
